# Dan Pu Academic Homepage

This folder contains the English academic homepage for Dan Pu. It is a static site and can be opened directly in a browser or published with GitHub Pages.

## Local preview

From this directory, run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## GitHub Pages

1. Push the contents of this folder to a GitHub repository.
2. Open the repository's **Settings -> Pages**.
3. Select the `main` branch as the deployment source.

The homepage uses `assets/dan-pu.jpg` as the profile photo. Update `index.html` when adding more biographical information or publications.

The original template attribution is retained in the footer and the license file. The site is based on [Plain Academic](https://github.com/mavroudisv/plain-academic) by Vasilios Mavroudis.
